# Sadat's Next.js Starter

A reusable professional starter for **Next.js + JavaScript + Tailwind CSS**.

## Included

- Next.js App Router
- JavaScript
- Tailwind CSS
- ESLint
- Lucide React
- Responsive Navbar and Footer
- Reusable Button, Input, Loading and Modal components
- Custom hooks
- Utility helpers
- API-ready service structure
- Environment variable example
- `@/` import alias
- Git-ready setup

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Lint

```bash
npm run lint
```

## Before Starting a New Project

1. Rename the project in `package.json`.
2. Update metadata in `app/layout.jsx`.
3. Copy `.env.example` to `.env.local`.
4. Replace the sample homepage.
5. Remove routes/components you do not need.
6. Add project-specific dependencies only when required.

## Suggested Growth

Keep this base template lightweight. Add authentication, database, payments, forms, validation, data fetching, etc. only when a project needs them.
